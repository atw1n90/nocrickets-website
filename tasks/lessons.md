# Lessons

- 2026-07-26: Confirm the real project root before creating P1 trackers or editing files.
- 2026-07-26: In PowerShell, do not use `Copy-Item -LiteralPath` with a wildcard; enumerate files first or use `-Path` so uploaded asset folders actually copy.
- 2026-07-27: For exported single-file HTML bundles, keep browser `<title>` text ASCII-only unless the file's full encoding path has been verified end to end.
- 2026-10-18: Before releasing a third-party browser SDK, verify its production CSP requirements in the live browser as well as testing the local callback flow.
