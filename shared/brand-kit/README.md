# NoCrickets Brand Kit

This folder is the source of truth for reusable NoCrickets logo and brand assets.

## Files

- `logo-neon.svg` - full NoCrickets neon wordmark for brand/reference use.
- `logo-neon-mark.svg` - compact `nc` neon mark source file.
- `nocrickets-meta-logo-1024.png` - square 1024x1024 upload asset for Meta Business and similar profile/logo upload fields.
- `brand-board.png` and `brand-board.html` - visual brand reference board.

## Related Shared Assets

Favicons live in `../favicons/`.

Current website and onboarding pages load favicons, fonts, and color tokens from `/shared/...`. Avoid adding duplicate logo/favicon copies under `/website` or `/onboarding` unless a platform specifically requires a generated export.
